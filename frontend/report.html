📑 1. Executive Summary & Problem Scope

Urban mobility, remote work culture, and rising real-estate setup expenses have drastically shifted consumer preferences from permanent asset ownership to flexible subscription models. However, legacy rental platforms suffer from rigid contracts, opaque pricing, manual paperwork, and severe user anxiety regarding space constraints.

RentEase AI resolves these roadblocks through an intelligent, end-to-end full-stack platform that seamlessly blends Conversational AI, Spatial Room Scanning, Dynamic Tenure Economics, and Automated Logistics Compliance.

🤖 AI Natural Language Search

Users express furnishing needs naturally. The AI translates unstructured prompts into structured query filters without ever hallucinating inventory.

📷 Spatial AR Camera Scanner

Live camera room capture directly in the browser suggests optimal furniture bundles mapped to physical room proportions.

💎 Rent-to-Own Equity

Every monthly payment builds credit toward permanent ownership with an automated buyout calculation formula.

⚡ Zero-Downtime Resilience

Dual-mode persistence: full MongoDB Atlas integration coupled with instant in-memory fallback preloaded with 150 items.

🛠️ 2. Technology Stack & Design Rationale

Layer Technologies Engineering Justification
Client Layer Vanilla JavaScript (ES6+), HTML5, CSS3, MediaDevices API Ultra-fast initial render (<300ms), zero dependency bloat, native browser compatibility, lightweight footprint.
Application API Node.js & Express.js (v5.x) Asynchronous, non-blocking I/O event loop ideal for handling concurrent rental orders, auth, and AI completions.
Database & ORM MongoDB & Mongoose (v8.x) Document-oriented flexibility for dynamic product attributes, embedded order line-items, KYC proofs, and user profiles.
Artificial Intelligence OpenAI API (`gpt-4.1-mini`) + Regex NLP Engine Hybrid intelligence: cloud LLM reasoning when API key is active, deterministic regex parser fallback for 100% offline uptime.
Security & Middleware JWT, bcryptjs, In-Memory Rate Limiter, HTTP Security Headers Protection against brute-force attacks, XSS injection, clickjacking, and unauthorized administrative access.

📡 3. REST API Specification Matrix

HTTP Method Endpoint Path Authentication Description
POST /api/auth/register Public Registers a new user with salted bcrypt password hashing.
POST /api/auth/login Public Authenticates credentials and returns signed JWT token.
GET /api/products Public Fetches inventory with keyword, category, and price ceiling filters.
POST /api/products/check-pincode Public Validates 6-digit Indian pincode against delivery hubs.
POST /api/orders User JWT Creates a rental contract with tenure discount and security deposit.
POST /api/orders/:id/kyc User JWT Submits government identity proof for order verification.
GET /api/orders/:id/buyout-estimate User JWT Calculates residual buyout price for permanent asset ownership.
POST /api/ai/chat Rate Limited Conversational chatbot assistant with product recommendations.
GET /api/admin/stats Admin Role Retrieves business intelligence metrics (orders, revenue, catalog).
PUT /api/admin/orders/:id/status Admin Role Updates delivery dispatch status along customer timeline.
